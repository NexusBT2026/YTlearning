## 🎯 Key Concepts

### What is a Sprint?

A sprint is a fixed time-box (usually 1-4 weeks) during which a team works to complete a set of stories.

### Sprint Planning

Sprint planning asks:
- Which stories fit in this sprint?
- What's the sprint goal?
- Can we commit to this?
- What could go wrong?

### Capacity Planning

Understand:
- How much work can your team do in a sprint?
- How many points (complexity) can you commit to?
- What's the buffer for unexpected issues?
