## 💡 Key Concepts Explained

### Execution Phase
The phase where BMAD takes your planning (stories, epics, architecture) and produces real deliverables (scripts, code, documentation, checklists).

### Sprint Execution
Running use the bmad-execute-sprint skill, which processes all stories in a sprint simultaneously and generates production artifacts.

### Deliverables
For each story:
- Video script (full transcript)
- Code example (if applicable)
- README (learning guide)
- Assets checklist (production notes)
- GitHub folder structure (ready to populate)

### Production Checklist
BMAD generates `execution-sprint-1.md` showing:
- What's been generated ✅
- What's left to do ⏳
- Deliverables for each story
- Production notes
- Next steps

### BMAD Loop Continues
The Loop keeps running in background:
- Tracking your progress
- Updating `deferred-work.yaml`
- Managing sprint status
- Coordinating with GitHub
