**Title:** `Real Projects — Episode 3 — Building a Unified Data Collector (REST + Websocket)`

**Description**

In this video, we build the third module of the Real Projects series: a unified Data Collector in Python.

This collector fetches historical REST data, listens for real‑time websocket updates, handles logging, supports environment variables, and prepares data for future modules like the Strategy Engine.

We also test the module with a demo script to confirm everything works correctly.

What we build in this video:
- DataCollector class with async/sync coordination
- REST API integration for historical data fetching
- WebSocket integration for real-time streaming
- Proper logging for both connection types
- Environment variable support
- Demo script using real Binance data
